Entry for the [Notes From a Passive-Aggressive Fridge](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7) bounty on make.fun.

`main.py` (Python 3, stdlib only) writes one funny passive-aggressive note
that a smart fridge leaves for its owner to `entry.txt` — a single line,
dry, petty and specific.

Run it:

```sh
python3 main.py
```

It writes `entry.txt` in the current directory, or in
`$MAKEFUN_OUTPUT_DIR` when that is set.
